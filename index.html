Command guide

Справочник команд клиента. Команды выполняются на выбранном компьютере через Telegram или административную панель. Доступные действия зависят от версии клиента и установленных плагинов.

Открыть справочникКоманды Telegram

Экран и мышь

  • screenshot

    Сделать скриншот всего экрана.

  • screenshot_region x y w h

    Скриншот выбранной области.

  • screen_size

    Разрешение экрана.

  • mouse_move x y

    Переместить курсор.

  • mouse_click [x y] [right|double]

    Щелчок мышью.

  • mouse_scroll n

    Прокрутка колёсика.

  • mouse_pos

    Текущие координаты курсора.

  • mouse_drag x1 y1 x2 y2

    Перетащить мышью.

Клавиатура

  • type_text text

    Ввести текст.

  • hotkey ctrl c

    Нажать сочетание клавиш.

  • press_key enter

    Нажать одну клавишу.

  • clipboard_get

    Получить текст буфера обмена.

  • clipboard_set text

    Установить текст буфера.

  • clipboard_history

    История буфера, если поддерживается.

Файлы и папки

  • pwd

    Текущая рабочая папка.

  • cd path

    Изменить рабочую папку.

  • ls [path]

    Список файлов; также алиасы dir и sd.

  • read_file path

    Прочитать файл.

  • write_file path | content

    Записать содержимое файла.

  • download_file path

    Подготовить файл к скачиванию.

  • create name | content

    Создать файл.

  • delete_file path

    Удалить файл.

  • copy_file src | dst

    Копировать файл.

  • move_file src | dst

    Переместить файл.

  • mkdir path

    Создать папку.

  • find_file pattern [path]

    Найти файлы.

  • recent_files

    Недавно изменённые/использованные файлы.

  • zip_folder path

    Архивировать папку.

Система и сеть

  • status

    Сводка о состоянии компьютера.

  • sysinfo

    Информация об ОС и оборудовании.

  • cpu

    Загрузка процессора.

  • ram

    Использование памяти.

  • disk

    Использование диска.

  • uptime

    Время работы системы.

  • battery

    Состояние батареи.

  • temp

    Температурные данные, если доступны.

  • processes [n]

    Список процессов.

  • kill_process name

    Завершить указанный процесс.

  • whoami

    Текущий пользователь.

  • env

    Переменные окружения.

  • network

    Сводка о сети.

  • connections

    Сетевые соединения.

  • public_ip

    Публичный IP.

  • ping_host host

  • traceroute host

    Маршрут до узла.

    Список Wi-Fi сетей.

  • wifi_password

    Информация о сохранённых Wi-Fi профилях — использовать только на своём устройстве с разрешением владельца.

Дополнительные команды клиента

    Показать рабочий стол.

  • task_manager

  • set_resolution width height

    Прочитать значение реестра Windows.

  • add_startup

  • remove_startup

  • prank_update

  • update_server

    Изменить адрес сервера клиента.

  • update_name

    Изменить имя клиента.

  • update_secret

    Обновить секретный ключ клиента.

  • version

    Показать версию клиента.

  • voice_mics

    Список доступных микрофонов.

  • voice_test

    Проверить голосовую подсистему.

  • check_update

    Проверить наличие обновления.

  • restart_update

    Перезапустить клиент для применения обновления.

  • uninstall

    Удалить клиент; сначала убедитесь, что это нужный компьютер.

  • hello

    Тестовая команда.

  • my_task

    Показать доступные сведения о текущей задаче.

  • dir

    Алиас команды ls.

  • sd

    Алиас команды ls.

Команды и плагины

  • accept [file]

    Поддерживается не во всех версиях клиента.

  • plugin commands

    Команды зависят от установленных плагинов; список запрашивается через Plugins в Telegram.

  • /and

    Цепочка команд: пример screenshot /and notify Done. Выполняйте только понятные и разрешённые действия.

Telegram bot

  • /start

    Начало работы и меню пользователя.

  • /guide

    Открывает этот справочник в браузере и показывает команды, доступные вашей роли.

  • /panel

    Ссылка на веб-панель администратора (для администраторов).

  • /scripts, /online, /offline

    Список компьютеров и статус.

  • /send <computer> <command>

    Отправить команду компьютеру (администратор).

  • /broadcast <command>

    Отправить команду всем онлайн-компьютерам (администратор).

  • /sessions, /users

    Сессии и привязанные пользователи.

  • /bind, /unbind

    Управление привязками.

  • /pair <computer>, /claim <code>

    Безопасное связывание через одноразовый код.

  • /group, /groups, /renamegroup

    Управление группами компьютеров.

  • /moderator, /moderators, /modremove

    Управление модераторами.

  • /remove <computer>

    Удалить из списка только отключённый компьютер.

Примечание: команды клиента определяются установленной версией и плагинами. На данный момент в клиентском реестре обнаружено 92 core command names/aliases; список выше отражает поддерживаемые имена, а некоторые команды могут иметь дополнительные аргументы.
